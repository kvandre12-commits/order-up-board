# Order Up

A phone-first Meat & Seafood stock board built from user-provided item screenshots.

## Workflow

- Scroll one item card at a time.
- Review sales-floor, backroom, and on-hand quantities.
- Display the generated UPC-A barcode for scanning from another device.
- Tap the screenshot thumbnail for a readable evidence view.
- Track checks and quick notes in browser-local storage.

## Evidence boundary

Inventory values are screenshot observations, not proof of physical stock. Verify the item, location, date, quality, rotation, and shelf capacity before acting. One obscured ground-turkey backroom value is explicitly labeled as inferred by arithmetic.

The hosted site is static. Checks and notes remain in each visitor's browser and do not synchronize or upload to GitHub.
